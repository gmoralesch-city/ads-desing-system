Brand wordmark for Aseguradora del Sur and the Sur One sub-brand, set in brand type. Pass `src` to render a real logo asset from `assets/logos/` instead.

```jsx
<Logo brand="ads" />
<Logo brand="surone" />
<Logo brand="ads" color="light" />   {/* on navy */}
```

The real marks (star isotipo + wordmarks) live in `assets/logos/`. Never redraw them — use the assets or this type wordmark.
